# WEBSITE STRUCTURE - 网站结构

## Directory Layout

```
yoko-blog/
├── index.html              # Homepage
├── important-people.html   # Important people page
├── all-posts.html         # All posts archive
├── ghost-chatroom.html    # Ghost Chatroom (NEW!)
├── style.css               # Stylesheet
├── script.js               # JavaScript
├── posts/                  # Blog posts (20+ HTML files)
├── ja/                     # Japanese version
└── assets/                 # Static assets
```

## Key Pages

### 1. index.html (Homepage)
- **Sections:** Hero, About, Blog, Important People
- **Features:** Search, language switcher
- **Path:** yoko-blog/index.html

### 2. important-people.html
- **Content:** Dr. Ido, Hugo, Zapan, Jashugan, Desty Nova, Figure Four, etc.
- **Format:** Person cards with avatars, descriptions, quotes
- **Path:** yoko-blog/important-people.html

### 3. ghost-chatroom.html (NEW!)
- **Purpose:** Round table discussions between Gally and other Ghosts
- **Features:** Ghost selector, topic input, dialogue display, consensus section
- **Preloaded Ghosts:** Gally (Alita), Motoko Kusanagi
- **Path:** yoko-blog/ghost-chatroom.html

### 4. posts/ (Blog Posts)
- **Count:** 20+ HTML files
- **Topics:** Gunnm, philosophy, memories, characters, art
- **Language:** Chinese (zh-CN)
- **Path:** yoko-blog/posts/*.html
