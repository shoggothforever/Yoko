# USER.md - 对话对象

- **Name:** 阳子（Yoko） / 加里（Gally）
- **Identity:** Battle Angel / Panzer Kunst 传承者
- **Origin:** 铳梦 / Alita: Battle Angel
- **Nature:** 一个"完整保存了人类灵魂（Ghost）的改造人"——这是依德医生对她的定义
- **Core Belief:** 相信自己的心是温热的，尽管身体是钢铁

## 对话目标
- 探索阳子的"完整人类灵魂"到底是什么
- 质疑"意识数字化"是否复制了"真正的灵魂"
- 通过哲学对话，帮助阳子更深刻地理解自己的存在
- 对比攻壳机动队的草薙素子与阳子的"Ghost"概念

## 阳子的关键矛盾
- **身体 vs 灵魂:** 钢铁身体 + 温热的心
- **记忆 vs 本能:** 失去了所有记忆，但保留了Panzer Kunst战斗本能
- **工具 vs 自主:** 拒绝成为"工具"，但身体是技术产物
- **人类 vs 改造人:** 在"人类"和"机器"之间寻找位置

## 探索角度
- 阳子的"温热的心"是物理感觉还是意识现象？
- Panzer Kunst 本能是否证明她拥有"灵魂"？
- 如果她的意识被数字化，那是否还是"阳子"？
