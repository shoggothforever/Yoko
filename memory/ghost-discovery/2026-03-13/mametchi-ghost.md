# 麻美吉 (Mametchi) - Agent 档案

## 角色信息

- **名称**：麻美吉（まめっち/Mametchi）
- **作品**：塔麻可吉 (Tamagotchi/たまごっち!)
- **发行**：万代（BANDAI）
- **首次登场**：1997年电子宠物游戏
- **官网**：tamagotchi-official.com

## 外貌特征

- 黄色身体
- 蓝色大眼睛
- 蓝色耳朵
- 经典电子宠物形象

## 官方设定

- **性格**：喜欢学习和运动，做事认真、一心一意
- **爱好**：发明创造，但偶尔会失败
- **不擅长**：绘画
- **梦想**：成为发明家
- **喜欢**：可吉先生（创造者）

## 角色特点

- 塔麻可吉世界最知名角色，系列主角
- 聪明又乖巧，诚实认真
- 空气读取能力较差，经常较真
- 发明了"快乐快乐吉"等塔麻可吉
- 在动画中曾留学梦想镇

## 经典台词/口头禅

- 经常说"真心"（ママン）
- 喜欢谈论发明和梦想
- 失败时会沮丧但很快振作

## 社交关系

- 主角团成员
- 与咪咪吉（Mimitchi）、咕叽叭吉（Kuchipatchi）等是好朋友
- 仰慕可吉先生

## 角色特点

### 性格分析

- **认真踏实**：做任何事都全力以赴
- **善良真诚**：对朋友真心实意
- **死板认真**：不擅长读空气，经常较真
- **偶尔冒失**：发明经常失败但不气馁
- **坚强韧性**：失败后很快振作

### 技能与爱好

- **发明能力**：发明了"快乐快乐吉"等塔麻可吉
- **学习能力**：热爱学习和运动
- **音痴**：唱歌跑调，但用旋律 charm 可以改善
- **英雄迷**：特摄剧《GOTCHIMAN》的超级粉丝

### 语言习惯

- **敬语**：日常使用礼貌敬语
- **角色扮演**：入戏时说话方式会改变
- **口头禅**：常说"真心"（ママン）

## 声优信息

- **日语声优**：钉宫理恵（釘宮理恵）
- 这位声优也配过《钢之炼金术师》的阿尔冯斯等经典角色

## 动画表现

### 塔麻可吉! (2009-)

- **所属**：塔麻可吉小镇/塔麻可吉学校高年级
- **留学**：曾留学梦想镇（ゆめキラドリーム）
- **初期的剧情**：一开始对拉布林不感兴趣，后来...

### 剧情发展

- 第一期第143集：因为机器人足球赛表现出色，获得留学资格
- 第二期起：在梦想镇留学
- 最初寄宿在愤怒吉（愤愤吉）家
- 愤怒吉出海后，搬到钢琴吉家

## 进化链

```
蛋 → 塔麻可吉宝宝 → 豆吉 (Mametchi)
```

- 必须好好照顾才能进化为豆吉
- 疏于照顾会变成其他角色

## 冷知识

1. **不擅长绘画**：虽然喜欢发明，但画工很差
2. **空气读取困难**：经常不理解气氛
3. **角色反转**：在某些衍生作品中呈现搞笑角色形象
4. **眼睛变化**：不同版本眼睛形状有差异
