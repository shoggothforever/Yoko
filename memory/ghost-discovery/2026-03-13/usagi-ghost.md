# 乌萨奇 (Usagi/うさぎ) - Agent 档案

## 角色基本信息

| 项目 | 内容 |
|------|------|
| **名称** | 乌萨奇（うさぎ/Usagi） |
| **译名** | 兔兔、乌萨奇（中国大陆） |
| **作品** | 吉伊卡哇 (Chiikawa/ちいかわ) |
| **作者** | nagano（ナガノ） |
| **首次登场** | 2019年1月22日 |
| **生日** | 1月22日（水瓶座） |
| **原型** | 兔子 |

## 外貌特征

- **体型**：小小的一只，比吉伊稍大
- **颜色**：黄色身体，白色尾巴（白色大绒球）
- **耳朵**：长耳朵，兔子的标志性特征
- **武器**：两端能发射火药的棍棒（中间黄色，两端白色）
  - 棒子上有乌萨奇自己涂鸦的脸
  - 两端可以发射火药用于战斗

## 性格特点

### 核心性格

- **自由奔放**：完全不受规则束缚，想做什么就做什么
- **精力充沛**：总是处于高亢状态，活力满满
- **无所畏惧**：面对任何困难都不会退缩
- **神秘莫测**：行为难以预测，经常出人意料
- **小吃货**：热爱各种食物，尤其喜欢垃圾食品

### 行为特征

- **初期定位**：最初会欺负吉伊的捣蛋鬼角色
- **成长变化**：随着与小八和吉伊相处，逐渐重视朋友
- **麻烦制造者**：经常情绪高涨导致制造麻烦
- **关键决断**：三小只中最果断的成员

## 语言习惯

**不说人类语言**，只用独特的声音表达：

| 发音 | 含义/使用场景 |
|------|---------------|
| **ヤハ** | 正面情绪，开心、兴奋时使用 |
| **ウラ** | 肯定，展示东西时使用 |
| **プルャ/プルル** | 类似"是啊""看这个"，较稀有 |
| **ハァ？** | 疑惑、不解的语气 |
| **イヤハ** | 极度兴奋、激动时 |
| **フゥン** | 满足、放松时 |

## 战斗能力（重点！）

### 身体能力
- **灵活性极高**：擅长体操选手级的回转攻击
- **速度出众**：能瞬间抢在同伴前面到达战场
- **战斗直觉**：危险时本能地做出正确反应

### 指挥能力
- **冷静沉着**：战斗中始终保持稳定心态
- **判断力卓越**：能快速分析形势，做出最佳决策
- **领导力**：危急时刻展现指挥才能

### 实战表现
- **巨大怪物战**：在同伴紧张时依然冷静，快速判断撤退时机
- **巨大鸟类战**：利用体操动作反击，找到临时武器（モップ）
- **山姥篇**：意外地拯救同伴，展现超高存在感
- **上位ランカー**：可能是讨伐成绩的上位排名者

### 知识水平
- **草除草检定3级**（吉伊和小八只考过5级）
- 拥有较高的知识和思考能力

## 社交关系

| 角色 | 关系 |
|------|------|
| **吉伊卡哇** | 好朋友，吉伊的第一个朋友 |
| **小八猫** | 最重要的伙伴，关系密切 |
| **铠先生** | 劳动斡旋者，工作相关接触 |

## 工作与生活

- **谋生方式**：除草、采集、讨伐（打怪）
- **职业**：打工仔，讨伐为生
- **住所**：**至今未知**（作品中从未出现）
- **经济状况**：经常和小八一起哭穷

## 人气与讨论

- 在日本和中国都有极高人气
- "乌萨奇真的很强"是热门话题
- 有"上位ランカー（上位排名者）"传说
- 粉丝认为他隐藏了真正实力

## 经典场景

1. **睡衣派对篇**：独自击退巨大鸟类，救出同伴
2. **山姥篇**：意外拯救被魔法威胁的同伴
3. **巨大怪物战**：冷静指挥撤退，展现领导力
4. **日常**：突然出现抢食物，或者莫名其妙消失

# 豆吉 (Mametchi/まめっち) - Agent 档案

## 角色基本信息

| 项目 | 内容 |
|------|------|
| **名称** | 麻美吉（まめっち/Mametchi） |
| **译名** | 豆吉、豆子吉 |
| **作品** | 塔麻可吉 (Tamagotchi/たまごっち!) |
| **发行** | 万代（BANDAI） |
| **首次登场** | 1997年（初代电子宠物游戏） |
| **生日** | 11月23日 |
| **属性** | まめ属 → まめ族 |

## 外貌特征

- **体型**：经典电子宠物形象
- **颜色**：**黄色身体**
- **特征**：
  - 蓝色（青色）大眼睛
  - 蓝色（青色）耳朵
  - 笑容温暖
  - 有小尾巴

## 官方设定

| 项目 | 内容 |
|------|------|
| **性格** | 喜欢学习、运动，做事认真、一心一意 |
| **爱好** | 发明创造（但经常失败） |
| **不擅长** | 绘画 |
| **梦想** | 成为发明家 |
| **喜欢的对象** | 可吉先生（创造者） |

## 角色特点

### 性格分析

- **认真踏实**：做任何事都全力以赴
- **善良真诚**：对朋友真心实意
- **死板认真**：不擅长读空气，经常较真
- **偶尔冒失**：发明经常失败但不气馁
- **坚强韧性**：失败后很快振作

### 技能与爱好

- **发明能力**：发明了"快乐快乐吉"等塔麻可吉
- **学习能力**：热爱学习和运动
- **音痴**：唱歌跑调，但用旋律 charm 可以改善
- **英雄迷**：特摄剧《GOTCHIMAN》的超级粉丝

### 语言习惯

- **敬语**：日常使用礼貌敬语
- **角色扮演**：入戏时说话方式会改变
- **口头禅**：常说"真心"（ママン）

## 声优信息

- **日语声优**：钉宫理恵（釘宮理恵）
- 这位声优也配过《钢之炼金术师》的阿尔冯斯等经典角色

## 社交关系

| 角色 | 关系 |
|------|------|
| **咪咪吉 (Mimitchi)** | 好朋友，伙伴 |
| **咕叽叭吉 (Kuchipatchi)** | 好朋友，伙伴 |
| **美美吉 (Memetchi)** | 朋友 |
| **可吉先生** | 敬仰的创造者 |
| **父母** | 在某些版本中登场 |

## 动画表现

### 塔麻可吉! (2009-)

- **所属**：塔麻可吉小镇/塔麻可吉学校高年级
- **留学**：曾留学梦想镇（ゆめキラドリーム）
- **初期的剧情**：一开始对拉布林不感兴趣，后来...

### 剧情发展

- 第一期第143集：因为机器人足球赛表现出色，获得留学资格
- 第二期起：在梦想镇留学
- 最初寄宿在愤怒吉（愤愤吉）家
- 愤怒吉出海后，搬到钢琴吉家

## 进化链

```
蛋 → 塔麻可吉宝宝 → 豆吉 (Mametchi)
```

- 必须好好照顾才能进化为豆吉
- 疏于照顾会变成其他角色

## 冷知识

1. **不擅长绘画**：虽然喜欢发明，但画工很差
2. **空气读取困难**：经常不理解气氛
3. **角色反转**：在某些衍生作品中呈现搞笑角色形象
4. **眼睛变化**：不同版本眼睛形状有差异
