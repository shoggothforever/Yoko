# 《最终秩序》 / Battle Angel Alita: Last Order

## 基本信息
- **时间线**：ES 591 (AD 2547) 左右
- **定位**：原版《铳梦》的续集，但与原版结局不同
- **忽略原版结局**：忽略了 Ketheres 变成纳米技术太空花、阳子变成血肉之躯人类、与 Figure Four 重逢的情节

## 主要剧情
### 开篇：复活与萨雷姆内战
- 故事从阳子被电大人的纳米技术在萨雷姆复活开始——此时距离她被电大人的「娃娃炸弹」杀死已经过去一年
- 萨雷姆的秘密被公开，引发了残酷的萨雷姆内战
- 但萨雷姆和地面只是更复杂世界的一小部分

### 太空之旅与星际冲突
- 阳子和新老同伴一起进入太空，去营救失去的朋友 Lou Collins
- 同时寻找更多关于她被遗忘的过去的信息
- 阳子卷入了殖民太阳系的主要势力之间的星际斗争

### 第十届顶点事物锦标赛 (ZOTT)
- 阳子进入了 LADDER 赞助的「第十届顶点事物锦标赛」（ZOTT）——这是一个每十年举办一次的太阳系级格斗锦标赛
- 在 ZOTT 中，阳子与三个前 TUNED 特工（现在已经开始独立思考）、一个令人讨厌的超级黑客 Ping Wu，甚至电大人本人结成了联盟
- ZOTT 是《Last Order》的主要故事弧，持续数天

## 世界观拓展
- 揭示了更多《铳梦》世界观的背景信息
- 解释了地球是如何从一场灾难性的撞击冬天中崛起的——那场灾难消灭了大多数人类
