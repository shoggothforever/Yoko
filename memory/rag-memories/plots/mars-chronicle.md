# 《火星战记》 / Gunnm: Mars Chronicle

## 基本信息
- **时间线**：交替在 ES 373-374 (AD 2329-2330) 和 ES 594 (AD 2550) 之间
- **定位**：讲述阳子（陽子/Yoko）在火星上的童年记忆

## 主要剧情
### 阳子的童年（ES 373年，火星）
- 背景：火星内战期间，这场内战最终导致了「地球化战争」（Terraforming Wars）
- 阳子（当时还是个年轻的改造人女孩）在流浪医生 Finch 的治疗下，结识了一个开朗的独眼女孩 Erica Walt
- Finch 给了阳子一个遥控器，帮助她更好地控制完全机械的身体
- 阳子和 Erica 被留在 Mamiana 镇的孤儿院，由一个叫 Ninon Silber 的女孩照顾——Ninon 是一群霸凌者的头目，自称是 Flammarion 统治家族的继承人
- Ninon 的朋友因为阳子的机械身体而霸凌她，直到 Erica 介入——这引发了 Erica 和 Ninon 之间的敌意（Ninon 想让 Erica 做她的仆人）

### 赏金猎人与 Papagei 军团
- 三个寻找阳子的赏金猎人出现：Das（改造人枪手）、Rocco（蜘蛛型改造人）、Gillatin（穿黑盔甲、用鞭剑的赏金猎人）
- 他们发现了一群被 Grünthal 杀死的士兵——这些士兵之前在《Last Order》里出现过，曾强迫阳子和 Erica 穿过雷区
- 第二天，Ninon 向阳子和 Erica 道歉，邀请她们去她在村庄水泵站的藏身处，还给阳子读了一个火星民间故事——展现了她善良的一面
- 但 Mamiana 镇突然被 Papagei 军团袭击，他们摧毁了小镇，屠杀了居民（包括 Ninon 和她的朋友）
- 阳子和 Erica 是唯一的幸存者，只是为了宣传目的
- Papagei 军团处理了尸体，将大屠杀归咎于敌对的 Winde 军团
- Finch 回到小镇，但晚了半天，错过了大屠杀——他接走了阳子和 Erica
