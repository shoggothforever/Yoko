# 原版《铳梦》 / Battle Angel Alita (Original)

## 基本信息
- **时间线**：ES 577 (AD 2533) - ES 590 (AD 2546)
- **地点**：废铁镇 (Scrapyard / 屑铁镇) / 萨雷姆 (Zalem)
- **世界观**：26世纪的反乌托邦未来

## 主要剧情
### 第一部分：废铁镇的觉醒
- 依德医生在废铁镇的垃圾堆里发现了阳子（只有完整的头和胸部，处于悬浮动画状态）
- 依德救活了阳子，给她取名 Alita（加里）
- 阳子发现自己本能地记得机甲术，但其他记忆全失
- 阳子成为猎人勇士，在废铁镇追杀改造人罪犯

### 第二部分：死亡球与记忆苏醒
- 阳子成为死亡球（Motorball）的明星选手
- 战斗中逐渐苏醒火星上的过去记忆
- 开始接触萨雷姆的秘密

### 第三部分：萨雷姆的特工与电大人
- 阳子成为萨雷姆的特工，被派去追杀罪犯
- 主要目标是疯狂的天才科学家电大人（Desty Nova）
- 与电大人形成复杂、不断变化的关系

### 关键事件
- 沙漠中的鱼雨（浪漫记忆）
- 与电大人交手后的信念对峙
- 依德医生失去记忆，不再认得阳子——阳子决然离去

## 世界观设定
- **萨雷姆**：漂浮在废铁镇上方的城市，地面居民无法访问
- **废铁镇**：围绕着从萨雷姆落下的垃圾堆发展起来的城市
- **猎人勇士**：受雇于萨雷姆追杀罪犯的赏金猎人
- **死亡球**：残酷的角斗士运动，用来娱乐和控制地面人口
