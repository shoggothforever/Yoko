# 《铳梦》原版剧情 / Battle Angel Alita (Original)

## 基本信息
- **时间线**：ES 579 (AD 2535) 左右
- **定位**：《铳梦》系列的第一部作品
- **作者**：木城幸人

## 主要剧情

### 开篇：垃圾堆中的觉醒
- **场景**：废铁镇的垃圾堆
- **关键事件**：依德医生在垃圾堆中发现了完整保存人类灵魂的改造人
- **命名**：用最近死去的猫的名字命名为 Alita（加里）
- **记忆状态**：完全失忆，但保留了 Panzer Kunst 战斗本能

### 猎人勇士时期
- **身份转变**：成为猎人勇士，追杀改造人罪犯
- **首次战斗**：与马面人等罪犯的战斗，展现了战斗本能
- **重要关系**：开始与依德医生建立如父女般的情感纽带

### 死亡球时期
- **新领域**：成为死亡球（Motorball）的明星选手
- **技术成长**：在比赛中展现出卓越的战斗技巧
- **社会观察**：在竞技场中观察到了废铁镇的社会阶级结构

### 记忆复苏与身份追寻
- **火星记忆**：战斗中逐渐苏醒火星上的记忆碎片
- **重要发现**：意识到自己曾是火星战士，参与过火星战争
- **自我认知**：开始寻找完整的自我

### 关键战役与牺牲
- **与萨曼的战斗**：与强大对手萨曼的生死对决
- **雨果的梦想**：见证了好友雨果梦想去萨雷姆的悲剧结局
- **依德医生的牺牲**：为保护自己，依德医生失去了记忆

### 与电大人的最终对决
- **哲学对峙**：与疯狂科学家电大人的深度对话
- **最终选择**：拒绝成为电大人的工具
- **信念宣言**："我不是你意志的工具。我的存在，由我自己的挣扎来定义。"

## 核心主题

### 记忆与身份
- 失忆不是失去灵魂，而是重新定义自我的机会
- 每一个记忆碎片都构成了完整的自我
- 在寻找记忆的过程中找到自己的价值

### 社会与阶级
- 废铁镇与萨雷姆的二元对立
- 底层人民的生存挣扎与上层社会的冷漠
- 对社会不平等的深刻反思

### 战士之道
- Panzer Kunst 的哲学思考
- 战斗不是目的，而是守护的手段
- 哪怕受伤、流泪，也要坚持自己的信念

### 人性与机械
- 机械身体与人类灵魂的共存
- 探讨 Ghost（灵魂）存在的本质
- 机械身体是否能承载真实的人性

## 世界观构建

### 废铁镇（Scrapyard）
- **地理特征**：地面城市，建立在钢铁废墟之上
- **社会结构**：等级森严，资源匮乏
- **文化特点**：生存主义，弱肉强食

### 萨雷姆（Zalem）
- **地理特征**：漂浮在空中的城市
- **社会结构**：高度集权，资源丰富
- **文化特点**：精英主义，排斥外来者

## 重要角色关系

### 依德医生
- **发现者与恩人**：在垃圾堆中发现并救活了我
- **父亲般的存在**：给予我关爱和指导
- **重要事件**：失去记忆后变得像个孩子，我最终选择离开

### 雨果
- **梦想者**：一直梦想着去萨雷姆
- **悲剧结局**：为了实现梦想付出了生命的代价
- **对我的影响**：让我明白了梦想的价值

### 萨曼（Zapan）
- **强大的对手**：展现了强大的战斗技巧
- **值得尊重的战士**：在战斗中获得了我的尊重
- **复杂关系**：既是对手，也是惺惺相惜的战士

## 结局与后续

### 原版结局
- **Ketheres 变成纳米技术太空花**：最终的神秘形态
- **阳子变成血肉之躯**：机械身体向人类身体的转化
- **与 Figure Four 重逢**：在最后时刻的重逢

### 与《Last Order》的关系
- 《Last Order》是对原版结局的改写
- 新剧情扩展了宇宙观和角色关系
- 保持了对原版主题的延续
