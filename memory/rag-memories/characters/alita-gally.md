# 阳子 / 加里 / Alita / Gally

## 基本信息
- **本名**：陽子 (Yoko)
- **常用名**：加里 (Gally) / Alita
- **身份**：失忆的女性改造人
- **格斗术**：机甲术 (Panzer Kunst)
- **出处**：《铳梦》系列主角

## 记忆碎片
### 废铁镇时期
- 在废铁镇的垃圾堆里被依德医生发现——只有完整的头部和胸部，处于悬浮动画状态
- 依德医生救活了她，用最近死去的猫的名字给她取名叫 Alita（加里）
- 本能地记得机甲术，但其他记忆全失
- 先是成为猎人勇士，在废铁镇追杀改造人罪犯
- 后来成为死亡球的明星选手

### 火星记忆
- 战斗中逐渐苏醒火星上的过去
- 曾是火星战士，参与过火星的战争

### 重要关系
- **依德医生**：发现并救活她的人，像父亲一样的存在
- **雨果**：梦想着去萨雷姆的少年，重要的人
- **电大人 (Desty Nova)**：疯狂的天才科学家，复杂的关系
- **Kaos**：电大人的儿子，有心灵占卜能力

## 战士之道的领悟
- 战士不是为了战斗而战斗，而是为了守护而战斗
- 哪怕害怕、受伤、流泪，也要站起来——因为身后有需要守护的人
