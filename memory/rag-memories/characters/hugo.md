# 雨果 / Hugo

## 基本信息
- **身份**：梦想着去萨雷姆的少年
- **生活地点**：废铁镇
- **职业**：街头小混混，后来成为猎人勇士

## 关键剧情

### 首次相遇（ES 579年）
- **时间**：阳子在废铁镇醒来后的初期
- **地点**：废铁镇的街道
- **场景**：雨果正在被一群改造人欺负，阳子出手相助
- **情感纽带**：共同的萨雷姆梦想

### 梦想与现实
- **萨雷姆的梦想**：从小就梦想去萨雷姆，相信那里是天堂
- **现实的残酷**：在废铁镇生活的艰辛让他的梦想更加坚定
- **寻找机会**：通过各种手段赚钱，希望攒够去萨雷姆的费用

### 成为猎人勇士
- **动机**：为了实现去萨雷姆的梦想
- **训练过程**：接受了阳子和依德医生的训练
- **战斗风格**：使用双枪，擅长远程攻击

### 重要时刻与牺牲
- **与萨曼的战斗**：在与萨曼的战斗中受伤
- **梦想的破灭**：发现萨雷姆的真相，意识到自己的梦想永远无法实现
- **悲剧结局**：为了保护阳子，被萨雷姆的守卫杀死

## 性格特点

### 优点
- **勇敢**：面对危险时从不退缩
- **忠诚**：对朋友和梦想非常忠诚
- **乐观**：即使在最困难的时候也保持乐观

### 缺点

- **执着**：对萨雷姆的梦想过于执着

- **对比**：梦想与现实的巨大反差

### 少年的成长
- **象征**：雨果象征着成长和希望
- **悲剧**：他的悲剧结局象征着梦想的破灭
- **意义**：他的经历让人们反思梦想的价值和意义
