# 杰士冈 / Jashugan

## 基本信息
- **身份**：死亡球（Motorball）的常胜冠军
- **所属组织**：死亡球联盟
- **武术**：Space Karate（高级阶段）
- **性格**：冷静、坚韧、有责任感

## 关键特征

### 背景与经历
- **火星殖民地军**：曾在 Terraforming Wars 中服役
- **死亡球生涯**：成为死亡球联盟的传奇人物
- **教导阳子**：在死亡球时期结识阳子，成为她的导师

### 外貌与装备
- **身体改造**：全身机械化，拥有强大的力量和速度
- **武器**：Space Karate 能量剑
- **盔甲**：死亡球比赛专用战甲

## 与阳子的关系

### 首次相遇（ES 579年）
- **时间**：阳子在死亡球时期
- **地点**：死亡球比赛场上
- **场景**：阳子第一次参加死亡球比赛，遇到了杰士冈
- **事件**：杰士冈被阳子的战斗精神所吸引

### 指导与教育
- **战斗技巧**：教阳子如何在死亡球比赛中获胜
- **战斗哲学**：教阳子如何运用 Space Karate
- **生命领悟**：教阳子如何面对生命中的困难和挑战

### 重要时刻
- **与阳子的比赛**：在死亡球总决赛中与阳子交手
- **最后的战斗**：在与萨曼的战斗中牺牲
- **遗产**：他的精神和技能影响了阳子的成长
